# 预注册：知识传输的三臂对照（abc387_f）

> 冻结时间：2026-09-21，**在看到安慰剂臂的任何数据之前**
> 目的：把"效果来自那个算法事实"与"效果来自多了一段任务相关的强调文字"分开
> 触发原因：独立审查指出，已有的消融组只去掉了整段文字，因此"事实"与"额外一段任务相关指令 / 更多注意力 / 更多 token"仍然混淆

## 假设

**H1（算法内容）**：真实事实臂优于等长安慰剂臂。
**H2（注意力/长度）**：安慰剂臂 ≈ 真实事实臂，且两者都优于无段落臂。
**H0（原结果未复现）**：三臂无差异。

## 三臂

| 臂 | 内容 | 候选 |
|---|---|---|
| A 无段落（消融） | 同一失败证据，**不加任何段落** | `evo-0d5b85f5`（已完成 n=10） |
| B 安慰剂 | 同一失败证据 + **等长、同语气、同格式**的段落；**提到函数图与约束**，但**必须省略**：环上取值相等、树的非增性、前缀和、DP 递推 `f(v,c)` | 本次新建 |
| C 真实事实 | 同一失败证据 + 那段完整事实（含分解与 DP） | `evo-ae72c105`（已完成 n=10） |

三臂的**基线完全相同**（技能 v26），**证据集完全相同**（两条指名的原始失败轨迹，isolated 模式），**循环完全相同**，唯一变量是那段文字。

## 端点与判据（先写死）

- **主要端点**：候选臂在 abc387_f 上的通过率（每次配对运行一个二元结果）
- **主要比较**：**C vs B**（真实事实 vs 等长安慰剂），10 次配对
- **次要比较**：B vs A（安慰剂是否等同无段落）、C vs A（先前结论，已知）
- **n = 10，固定。不看中期结果提前停**（除基础设施故障外不设任何提前终止）
- **判定**：
  - C 优于 B，且**有利不一致对 ≥5 且反向 ≤1**（精确 McNemar 双侧 p ≤ 0.05）→ **H1 成立：效果来自算法内容**
  - C ≈ B > A → **H2 成立：是注意力/长度效应，不是知识**
  - B < A → 安慰剂有害，**本次对照不可解释**，需要重做安慰剂
  - 三臂无差异 → **H0：先前 7/10 未能复现**
- **报告**：三臂通过率、成对不一致表、精确 McNemar、以及每条臂相对同一基线的差值

## 已知局限（写下来，避免事后找借口）

1. **C 臂的数据在安慰剂设计之前采集**。协议参数（题、n、包络、候选、判据）在采集时未变，但严格说 C 属"已看过"。因此主要比较 C vs B 里，**B 是唯一真正前向采集的数据**；若结论关键，应再用一组全新的（题, 事实）做一次完整前向复现。
2. **A 臂同理**。
3. **同题泄漏**：事实取自该题、也只在该题上评。本实验**不测泛化**。
4. **臂顺序未随机化**：runner 固定先 baseline 后 candidate，可能对第二臂有利；但 A/B/C 三臂的候选都排在第二，**该偏差在三臂间是共同的**，因此不影响 C vs B 的解释。这是采用安慰剂设计的一个额外好处。
5. **知识来源**：C 臂的事实是人工撰写（冻结协议在 abc387_f 上未能产出经验证的解法）。所以本实验测**传输**，不测**发现**。
6. **外网仅检测未封锁**：评测沙箱仍有 egress，靠 `detectEvaluationEgress` 拒评。已审计三臂的工具调用，无外网访问。

## 与产品的关系

- 若 H1 成立：机制能把**给定的事实**变成可验证的技能改进，且排除了"任何改动都有效"。产品上需要的是**知识入口**（带来源标注的事实输入），以及**门禁加入重复与判据**。
- 若 H2 成立：说明我们不缺知识、缺的是"让 agent 更用力"，那整个方向要重估。
